# DockMate has NO Python package dependencies.
#
# The script uses only the Python standard library:
#   pathlib, csv, math, re, shutil, subprocess, sys, time
#
# There is nothing to pip install. This file exists so that anyone looking
# for it finds this note instead of assuming something is missing.
#
# ---------------------------------------------------------------------------
# WHAT YOU DO NEED (installed separately, not via pip):
# ---------------------------------------------------------------------------
#
#   Python       >= 3.8
#                https://www.python.org/downloads/
#
#   UCSF Chimera 1.19 (or any 1.x with the `vina` command)
#                https://www.cgl.ucsf.edu/chimera/download.html
#                Free for non-commercial use.
#
#   AutoDock Vina  >= 1.1
#                https://vina.scripps.edu/downloads/
#                Must be installed LOCALLY. Chimera's original web-service
#                backend was retired on 30 April 2020, so DockMate always
#                runs Vina through `backend local`.
#
#                IMPORTANT: install or copy it to a path with NO SPACES.
#                Chimera's command parser splits arguments on whitespace.
#
# ---------------------------------------------------------------------------
